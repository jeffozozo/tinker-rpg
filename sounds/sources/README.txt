Ultima IV walking sound reference

ultima_iv_walk_normal_c64.wav is an unmodified copy of:
https://github.com/xu4-engine/u4/blob/master/module/Ultima-IV/sound/walk_normal_c64.wav
Retrieved November 15, 2026. It is identified by xu4 as the normal C64 walking
sample. This is not an Apple II sample or a claim that all Ultima ports match.

The upstream project is xu4 (Ultima IV Recreated). Its COPYING and module Credits
are included as GPL-3.0.txt and xu4-Credits.txt. The latter acknowledges that some
assets utilize copyrighted material. No additional license grant is asserted here.

The builder copies this WAV unchanged to step.wav. step_hurt.wav prepends the
same PCM click to the game's generated hurt effect, resampling only the hurt tail.
The remaining hit/miss/hurt sounds are generated by scripts/build_sound_effects.py.
